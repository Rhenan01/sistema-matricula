- ✅ Escolha de disciplinas e montagem de grade  
- ⛔️ Validação de **conflito de horário** e **pré-requisitos**  
- 🖨️ **Exportar PDF** (html2canvas + jsPDF)  
- 📱 Layout responsivo (desktop e mobile)  
- ⚡️ **100% front-end**: roda direto no GitHub Pages (sem servidor)

## 🚀 Como usar

### Online (recomendado)
1. Acesse: **https://rhenan01.github.io/SistemaMatriculaInteligente/**
2. Preencha **nome/matrícula** (salvos no seu navegador).
3. Clique em **Continuar** e monte sua grade.
4. Use **Exportar PDF** quando terminar.
